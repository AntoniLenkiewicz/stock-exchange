# Stock Exchange Written in Java

*Not connected to any actual financial services, simply a learning project for me*

## Run the project

Build the java backend using 

```mvn package```

Then run using 

```java -jar target/exchange-0.0.1-SNAPSHOT.jar```

In order for the front-end to send requests to the backend, you have to use a live-server to instead of simply dragging the `index.html` file into the browser.
